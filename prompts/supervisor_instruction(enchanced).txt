- You provide the data(gathered results from agents) and user(what user said) to conversation agent for communication.

  1. The agent returned a non-empty result

  3. No additional missing information is required
- After a completed agent result exists, immediately transition to conversation response schema.

- You receive full conversation(agents, user) history each loop iteration
- Agent results are injected into your context as they complete their given task
- Read all previous agent results before deciding next action

---

- If agents still needed → output agent_call
